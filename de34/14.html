データベース基礎まとめ

テーブル・フィールド・SQLなどの基本をわかりやすく解説

データベースとは

データベースとは、データを整理して保存し、必要なときに取り出せる仕組みです。 例えば、学校の成績やお店の顧客情報などに使われます。

テーブル・カラム・フィールド

データベースは「テーブル」という表の形でデータを管理します。

  • テーブル： データのまとまり（例：学生一覧）
  • カラム（列）： 項目（例：名前、年齢）
  • フィールド： 1つ1つのデータ

例：学生テーブル

ID 名前 年齢
1 田中 20
2 佐藤 21

SQLとは

SQL（Structured Query Language）は、データベースを操作するための言語です。

例：データを取得する

SELECT * FROM 学生;

→ 学生テーブルのすべてのデータを取得する

条件付き取得

SELECT * FROM 学生 WHERE 年齢 = 20;

→ 年齢が20歳のデータだけ取得

クエリとは

クエリとは、データベースに対する「問い合わせ」のことです。 SQL文を使ってデータを検索・追加・更新・削除します。

トランザクションとは

トランザクションとは、一連の処理を「まとめて安全に実行する仕組み」です。

  • 途中で失敗したら元に戻す（ロールバック）
  • 成功したら確定する（コミット）

例

銀行の振込処理では、 「引き出し」と「入金」をセットで成功させる必要があります。

まとめ

  • データはテーブルで管理する
  • カラムは項目、フィールドはデータ
  • SQLでデータを操作する
  • クエリは問い合わせ
  • トランザクションで安全に処理する
