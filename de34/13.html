KU-BizTech Portal アプリ制作

横浜市 すかいらーくグループ時給比較アプリ

① BizTech Portalとは

BizTech Portalとは、ビジネスとテクノロジーを組み合わせた学習を行うための環境であり、 実際にアプリケーションを作成しながらプログラミングやデータ活用を学ぶことができる。 特にPythonやFlaskなどを用いて、実用的なWebアプリを作る経験ができる点が特徴である。

② 作成したアプリの概要

横浜市内にあるすかいらーくグループのアルバイト時給を比較し、 時給の高い順にランキング表示するアプリを作成した。 利用者が一目でどの店舗が高時給か分かるように工夫した。

③ Python（Flask）コード

from flask import Flask, render_template
import os

app = Flask(__name__)

jobs = [
    {"name": "ガスト", "wage": 1150},
    {"name": "バーミヤン", "wage": 1150},
    {"name": "ジョナサン", "wage": 1200},
    {"name": "夢庵", "wage": 1150},
    {"name": "ステーキガスト", "wage": 1180},
    {"name": "しゃぶ葉", "wage": 1200},
    {"name": "から好し", "wage": 1180},
    {"name": "むさしの森珈琲", "wage": 1250}
]

@app.route("/")
def index():
    sorted_jobs = sorted(jobs, key=lambda x: x["wage"], reverse=True)
    return render_template("index.html", jobs=sorted_jobs)

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 3000))
    app.run(host="0.0.0.0", port=port)

⑤ 工夫した点

時給を自動で並び替える処理をPythonで実装し、常に高い順で表示されるようにした。 また、HTMLとCSSを使って見やすいデザインにし、順位が分かりやすいように表形式で表示した。
